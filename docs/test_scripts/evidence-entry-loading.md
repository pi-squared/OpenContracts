# Evidence entry through source loading

Use an isolated application/database copy with an existing processed PDF and a
completed extract. Use neutral synthetic findings with a located quotation and
an ambiguous quotation. Do not edit findings or source data, start extraction,
retry ingestion or dispatch a model call.

1. Open a located quotation from the original-value modal. Its ordinary source
   navigation must load and paint the actual PDF, reveal the exact owning
   source card, focus that card and visibly inspect the matching highlight.
2. Repeat by reloading the resulting source URL and by opening an effective
   finding's source link. Initial document annotations may be replaced by the
   extract's finding-specific projection; the explicit entry must survive that
   replacement and center the located quotation after it becomes available.
3. Press Escape from the actual PDF viewer. Re-render the source list, change
   zoom and refresh the same source projection. The dismissed entry must not
   reopen or cause a new PDF navigation request.
   Also pause the source-loading fixture after its initial annotations have
   disappeared and focus has automatically cleared. Press Escape while the
   projection is empty, then allow the source to return. It must stay dismissed.
4. Explicitly inspect another quotation, then repeat those stable renders,
   zoom changes and source refresh. The old URL entry must not replace that
   inspection. If refresh temporarily removes every source, an unavailable
   inspection may clear; the old entry must remain dismissed.
   Repeat with the manual inspection and empty replacement occurring in the
   same update. Returning sources must not restore the old URL entry.
5. Open a different finding/version/document. Its entry belongs to that new
   scope. A missing or unlocated legacy source must not inherit the prior
   highlight or trigger a source navigation request.
6. Confirm the ambiguous quotation remains visible without a selected source
   highlight, and that original/corrected values, comments, decisions and
   stored source associations are unchanged in raw before/after snapshots.

Capture native source-bound WebMs and actual API/DOM/source-state receipts for
the current head. Bind browser controls to the exact recorded page before
driving it; verify the full URL, not only the pathname. Preserve failed or
unrecorded setup attempts separately and exclude them from acceptance.

The focused hook regressions exercise real router, annotation and focus stores
through eligible/empty/restored data, delayed sources, original/effective
scope changes, Escape, another inspection, unavailable evidence, stable renders
and zoom. Timing controls include manual actions during absence and batched
with replacement, plus cancellation before the initial source arrives. Native
actual-PDF checks remain required.
